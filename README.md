# 今日は何の日

> 個人の試作・初版です。動作は参考情報で、保証はしません。

今日(または指定した日)の祝日・年中行事・記念日・国際デーを出し、行事食や話題を添えます。連休の探し方や、これから来る行事の一覧も出せます。個人の試作の初版で、参考情報です。

## 先に知っておいてほしいこと

- **日付・曜日・祝日の判定は付属のスクリプト(Python 3)がします。** AIの暗算ではありません。祝日は2022年以降の法律に基づいて計算し、振替休日・国民の休日も含みます
- 追加のライブラリは要りません(Pythonに最初から付いているものだけで動きます)
- **「〇〇の日」を365日分そろえた一覧ではありません。** 入っているのは、法律で決まった祝日、年中行事(五節句など)、政府・国連などが定めた記念日・国際デーを中心にした**小さな一覧**です。業界団体や企業が決めた「〇〇の日」の多くは、出典や利用条件がはっきりしないため入れていません
- 一覧に無い日は「入っていません。確かな出典で確認してください」と答える作りです(AIが覚えていても断定しません)
- 祝日の計算は1980〜2099年に対応しています。春分・秋分は近似式です。2022年より前は、当時の法律と祝日が異なる場合があります
- `SKILL.md` に対応しているAIツールで使える作りにしていますが、**動作確認は Claude Code(Windows)だけです。** ほかのAIツール・Mac・Linux は動く想定で、確認していません

## できること

- **今日(指定日)**: 祝日・年中行事・記念日・国際デーと、説明、行事食を出す
- **これから来る行事**: 今後30日などの行事の一覧を出す
- **連休の探し方**: 期間を指定して、土日祝がつながる休日と連休を出す
- 表示は文字の枠、または自分のPCで開くHTMLページです

## ほかのスキルとの連携(入っている時だけ)

同じ作者の別スキルが同じ場所に入っていると、連携して使います。入っていなくても単独で動きます。

- `占い`: 暦計算(二十四節気・節分・冬至・土用の丑・十五夜など)を使います。**入っていない場合、これらは出ません**(節分は目安の2/3になります)。このスキルは `占い` の暦計算のコードを読み込みます(同じスキル置き場にある場合だけ)
- `献立`: 行事食を献立に取り入れる
- `記念日`: 行事を毎年の記念日として登録する
- `旅行プラン`: 連休を旅行の日程候補に使う(旅行プランの出発日候補は、このスキルの祝日・連休の計算を使います)
- `気分日記`・`名言`: 行事の日の話題として組み合わせる

## 安全性について(何をするか、全部書きます)

「安全です」と言い切るより、何をするかを並べます。気になる人はコードを読んでください(スクリプトは `scripts/nanohi.py` の1本と、ページのひな形 `scripts/page.html` です)。

**やること**
- 日付から祝日・行事・記念日・国際デーを計算・検索して表示する
- `占い` が同じ場所に入っていれば、その暦計算のコードを読み込む(上の節)

**やらないこと**
- **インターネットへの通信は、スクリプトからは一切しません。** 外へ送るための仕組み(urllib・requests・socket など)は使っていません
- 個人の情報や予定を保存しません。ほかのファイルを読み書きしません(連携の暦計算の読み込みを除く)

**ひとつだけ注意**
- 「ページで出す」機能のひな形(`scripts/page.html`)は、見た目のために Google Fonts(フォント)を読み込みます。ページを開く時にだけ、フォントの取得で外部への通信が起きます

**消す** → スキルのフォルダを削除すれば、すべて消えます

## 入れ方

このフォルダの内容(`SKILL.md` と `scripts/`)を、お使いのAIツールのスキル置き場に `今日は何の日` という名前のフォルダで置きます。Claude Code なら `~/.claude/skills/今日は何の日/` です。

あとは「今日は何の日?」と話しかけます。

## 使い方

| やりたいこと | 話しかけ方 |
|---|---|
| 今日の行事を知る | 「今日は何の日?」 |
| これから来る行事を見る | 「来月の行事は?」 |
| 連休を探す | 「今度の連休はいつ?」 |

自己点検は `python scripts/nanohi.py check` で実行できます(祝日・振替休日の計算が合っているかを確かめます)。
